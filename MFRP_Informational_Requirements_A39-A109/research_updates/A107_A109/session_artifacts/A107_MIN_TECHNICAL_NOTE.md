# A107-MIN — First deterministic legacy gamma-plus continuum witness

## Frozen question
Does the first deterministic `legacy_three_band_gamma_plus` witness from A102 persist on a nonzero open interval of the source probe `s`, with the A102 support and active-band architecture kept fixed?

## Source selection
The A102 gamma-plus set contains 922 records. Records are sorted deterministically by `(maximum, compressed_contact, witness)`. The first record is

`M=14|b=3|phase=unique_b_plus_1|side=full|s=131/1000|j=4`.

Its source segment is `(129/1000, 133/1000)`, with

- `P={0,4,5,14}`
- `Q={1,7,8}`
- active bands `alpha+`, `beta-`, `gamma+`
- 37 strict finite-LP KKT conditions.

## Exact method
Only the alpha row varies with `s`. The audit uses the same exact rank-one Sherman–Morrison reduction, integer-polynomial conversion, root isolation, competing-root ordering, complete core/hull positivity certification, and rational outside counterexample standard used by A105–A106, adapted only by the frozen gamma-plus sign and support `P={0,j,j+1,M}`.

A direct matrix inversion implementation independently replays the symbolic rank-one system at four rational checkpoints. This gives 148 exact condition comparisons with zero mismatches.

## Result
Verdict: `PASS_LOCAL_OPEN_STABILITY`.

The first gamma-plus witness does **not** cover the complete A95 source segment. It lies in a proper strict subcomponent. The unique selected left boundary is generated by

`basic_p_5 = 0`,

that is, loss of the upper adjacent mass `p_{j+1}`.

The algebraic boundary is isolated in the exact rational bracket

`[39462775231797029312692347/302231454903657293676544000,
  157851100927188117250769389/1208925819614629174706176000]`,

with width

`1/1208925819614629174706176000`.

Numerically this root is approximately `0.13057137035712127`.

The certified witness-containing core therefore runs from just above that isolated root to the source upper endpoint `133/1000`. There is no selected right boundary.

A rational point to the left of the boundary,

`78450632914368820196966523/604462909807314587353088000`,

has `basic_p_5 < 0` under direct exact matrix evaluation. Thus the loss of the frozen gamma-plus basis below the boundary is genuine and is not merely a failure of the symbolic proof engine.

## Scope
This establishes local open stability for exactly one preregistered gamma-plus witness. It does not establish that all 922 gamma-plus witnesses have the same boundary mechanism, that all cover nonzero intervals, or that the mechanism is uniform in `M`.

## Methodological correction
The repository itself shows that the continuum variable here is the source probe `s`; only the alpha row varies with `s`. An earlier provisional `t=p2` parameterization was therefore not source-grounded and was discarded before this computation. No result above relies on it.
