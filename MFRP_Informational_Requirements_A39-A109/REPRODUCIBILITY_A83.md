# Reproducibility A83

A83 depends on the committed A80–A82 audit programs and the A82 result JSON. It recomputes all 1,367 sparse factors, exact reconstruction identities, local sign certificates, two algebraic root brackets, endpoint/probe sign sequences, and the exact second-difference census.

The decimal root values are display-only. Root isolation, sign decisions, factorization tests, and all gates use rational or integer arithmetic.

Scope: `10 <= M <= 80`, `2 <= k < floor(M/2)-1`, and `129/1000 <= s <= 133/1000`.
