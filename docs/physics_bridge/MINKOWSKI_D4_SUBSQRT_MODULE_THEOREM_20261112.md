# Theorem: sub-square-root exclusion of non-stable modules in 3+1 Minkowski sprinklings

**Date:** 2026-11-12  
**Author:** Felipe Gianini Romero  
**Status:** analytic growing-module theorem  
**Physical status:** internal UPO obstruction bound for arrow-erased \(3+1\)-dimensional Minkowski causal sets  
**Novelty status:** modular decomposition and splitter closure are classical; no equivalent geometry-induced sub-square-root module theorem was located in the targeted review

## 1. Statement

Let

\[
G_{4,n}
\]

be the unoriented causal-comparability graph of \(n\) iid uniform points in a fixed flat Alexandrov interval of \(\mathbb M^4\).

For every fixed

\[
\eta>0,
\]

\[
\boxed{
\Pr\!\left(
\exists\text{ proper non-stable graph module }M:
2\le |M|\le n^{1/2-\eta}
\right)
\longrightarrow0.
}
\]

Thus internal UPO obstructions of every polynomial size strictly below the square-root scale disappear asymptotically.

This is stronger than the previously proved fixed-size hierarchy.

## 2. Splitter-generated certificates

Let \(M\) be the minimal module generated by an internal edge.

Splitter closure starts from

\[
S_2=\{x_1,x_2\},
\qquad
x_1\sim x_2,
\]

and repeatedly adds every outside vertex that is adjacent to some but not all current members.

Every newly added splitter remains a splitter after further vertices are added, because it already has one adjacent and one nonadjacent witness among the earlier vertices.

Therefore, if

\[
|M|\ge r,
\]

we can order \(r\) members

\[
x_1,\ldots,x_r
\]

so that

\[
x_1\sim x_2,
\]

and for every

\[
m=3,\ldots,r,
\]

the point \(x_m\) is adjacent to some but not all of

\[
\{x_1,\ldots,x_{m-1}\}.
\]

Call such an ordered tuple a **splitter-generated \(r\)-certificate**.

## 3. k-way disagreement of the certificate

For the first \(r\) certificate points define

\[
\mathcal D_r
=
\left(
\bigcup_{i=1}^r A_{x_i}
\right)
\setminus
\left(
\bigcap_{i=1}^r A_{x_i}
\right),
\]

and

\[
\Delta_r
=
\mu(\mathcal D_r).
\]

Every point of \(\mathcal D_r\) distinguishes members of the certificate.

If the final module \(M\) has size at most \(K\), every sampled splitter of the certificate must lie inside \(M\).

Hence, conditioned on the certificate positions,

\[
N_r
\sim
\operatorname{Binomial}
(n-r,\Delta_r)
\]

satisfies the necessary condition

\[
\boxed{
N_r\le K-r.
}
\]

## 4. Fixed-r small-disagreement geometry

For each fixed

\[
r\ge2,
\]

define

\[
H_r(\varepsilon)
=
\Pr(
X_1,\ldots,X_r
\text{ form a splitter-generated certificate},
\;
\Delta_r\le\varepsilon
).
\]

Then in \(d=4\),

\[
\boxed{
H_r(\varepsilon)
=
O_r(\varepsilon^{2r-1})
\qquad
(\varepsilon\downarrow0).
}
\]

Only the upper bound is required for the module theorem.

## 5. Why the exponent is \(2r-1\)

The proof separates the codimension-two null joint from the ordinary bulk.

### Joint sector

For

\[
\Delta_r\le\varepsilon,
\]

every pairwise disagreement satisfies

\[
\Delta_2(x_i,x_j)\le\varepsilon.
\]

The first certificate edge has two possibilities:

1. an ordinary bulk near-diagonal pair;
2. a null-joint pair.

The bulk contribution is subleading, as discussed below.

For the null-joint contribution, the first point must have both null-depth coordinates of order

\[
O(\sqrt\varepsilon).
\]

Its two null coordinates contribute volume

\[
O(\varepsilon),
\]

while its global angular direction is unrestricted.

Because \(x_2\) is comparable to \(x_1\) and their disagreement is at most \(\varepsilon\), \(x_2\) must lie in:

- the same \(O(\sqrt\varepsilon)\) null-depth scale;
- an \(O(\sqrt\varepsilon)\) angular cap around the first direction.

Thus \(x_2\) contributes

\[
O(\varepsilon^2).
\]

Now suppose

\[
x_1,\ldots,x_{m-1}
\]

already lie in this joint chart.

The splitter condition says that \(x_m\) is adjacent to at least one earlier member.

Since

\[
\Delta_2(x_m,x_j)\le\Delta_r\le\varepsilon
\]

for every earlier \(x_j\), the same local-coordinate bounds force \(x_m\) into the same joint scale and angular chart.

Therefore every additional certificate vertex contributes

\[
O(\varepsilon^2).
\]

The total joint measure is

\[
O(\varepsilon)
\left[
O(\varepsilon^2)
\right]^{r-1},
\]

hence

\[
\boxed{
O(\varepsilon^{2r-1}).
}
\]

### Bulk sector

Away from the null joint, the pairwise disagreement map has nonzero linear response to local displacement.

Thus

\[
\Delta_2\le\varepsilon
\]

forces ordinary four-dimensional displacement

\[
O(\varepsilon).
\]

After choosing one root point, each of the remaining \(r-1\) points contributes

\[
O(\varepsilon^4).
\]

The bulk therefore contributes

\[
O(\varepsilon^{4(r-1)}).
\]

For every

\[
r\ge2,
\]

\[
4(r-1)>2r-1,
\]

so the bulk is subleading.

The remaining compact boundary charts have the same nondegenerate linear response and are bounded by the bulk order.

This proves

\[
H_r(\varepsilon)
=
O_r(\varepsilon^{2r-1}).
\]

## 6. Excluding modules up to a growing size \(K\)

Fix \(r\ge2\).

Let

\[
K=K_n
\]

satisfy

\[
K\to\infty,
\qquad
K\gg\log n.
\]

Choose a sufficiently large constant \(A\), and set

\[
t_n
=
A\frac Kn.
\]

Suppose a non-stable module \(M\) satisfies

\[
r\le|M|\le K.
\]

It contains a splitter-generated \(r\)-certificate.

Split possible certificates into two classes.

## 7. Small disagreement certificates

For

\[
\Delta_r\le t_n,
\]

the expected number of splitter-generated certificates is at most

\[
n^r
H_r(t_n).
\]

Using the fixed-\(r\) tail,

\[
n^rH_r(t_n)
\le
C_r
n^r
\left(
\frac Kn
\right)^{2r-1}.
\]

Therefore

\[
\boxed{
\mathbb E[
\#\text{ small-disagreement }r\text{-certificates}
]
=
O_r
\left(
\frac{
K^{2r-1}
}{
n^{r-1}
}
\right).
}
\]

This tends to zero whenever

\[
\boxed{
K
=
o\!\left(
n^{(r-1)/(2r-1)}
\right).
}
\]

## 8. Large disagreement certificates

Now suppose

\[
\Delta_r>t_n.
\]

Conditioned on the certificate,

\[
N_r
\sim
\operatorname{Binomial}
(n-r,\Delta_r)
\]

has mean at least

\[
(1-o(1))AK.
\]

For \(A\) sufficiently large, a Chernoff lower-tail estimate gives

\[
\Pr(
N_r\le K-r
\mid
\Delta_r>t_n
)
\le
e^{-c_AK}
\]

for some

\[
c_A>0.
\]

There are at most

\[
n^r
\]

ordered \(r\)-tuples.

Hence

\[
\Pr(
\exists\text{ large-disagreement certificate compatible with }|M|\le K
)
\le
n^r e^{-c_AK}.
\]

Since

\[
K\gg\log n,
\]

this tends to zero.

## 9. The fixed-r threshold

Combining the two regimes:

\[
\boxed{
\Pr(
\exists\text{ non-stable module }M:
r\le|M|\le K_n
)
\to0
}
\]

whenever

\[
\log n\ll K_n
=
o\!\left(
n^{(r-1)/(2r-1)}
\right).
\]

The exponent is

\[
\gamma_r
=
\frac{r-1}{2r-1}.
\]

The first values are

\[
\gamma_2=\frac13,
\]

\[
\gamma_3=\frac25,
\]

\[
\gamma_4=\frac37,
\]

and

\[
\gamma_r
\uparrow
\frac12.
\]

## 10. Completion below the square-root scale

Fix

\[
\eta>0.
\]

Choose a fixed integer \(r\) large enough that

\[
\frac{r-1}{2r-1}
>
\frac12-\eta.
\]

Then choose

\[
K_n
=
n^{1/2-\eta}.
\]

The fixed-\(r\) theorem excludes all module sizes

\[
r\le|M|\le K_n.
\]

The finitely many smaller sizes

\[
2\le|M|<r
\]

are already covered by the same certificate hierarchy at lower fixed orders.

In particular:

- size \(2\):
  \[
  \mathbb E[T_n]\sim9\pi/n;
  \]
- size \(3\):
  \[
  \mathbb E[M_{3,n}]=\Theta(n^{-2});
  \]
- every remaining fixed size has vanishing probability by its corresponding fixed certificate bound.

Therefore

\[
\boxed{
\Pr\!\left(
\exists\text{ proper non-stable module }M:
2\le|M|\le n^{1/2-\eta}
\right)
\to0.
}
\]

## 11. Independent graph-theoretic regression

The splitter-closure implementation

tools/minkowski_splitter_closure_audit.py

has already been regressed against the independent implication-class UPO classifier on all relative permutations through the tested exact range.

The k-way binary identities used in this proof are checked independently by

tools/verify_kway_module_disagreement.py.

Finite \(3+1\) audits increasingly concentrate all observed proper closures at size \(2\), with the size-\(3\) population becoming rare and no persistent growing-module population detected in the tested range.

Those simulations are diagnostic only.

## 12. Relation to graphon homogeneous sets

Graph modules are also called homogeneous sets.

Graphon literature extends this notion to weakly homogeneous measurable sets.

That established language is useful, but the present theorem is not an application of an existing random-graphon primeness theorem.

The proof uses:

1. Minkowski null-joint geometry;
2. the splitter-generated certificate structure;
3. the \(k\)-way disagreement volume;
4. binomial splitter counts.

A targeted search did not locate an equivalent theorem for \(G(n,W)\) sampled from a causal-comparability graphon.

## 13. What remains

The internal-module problem has now been reduced to the window

\[
\boxed{
n^{1/2-o(1)}
\lesssim
|M|
<
|C_n|.
}
\]

The component problem is already closed: all non-isolated vertices lie asymptotically in one component.

Thus the remaining obstacle to

\[
p_4^{\mathrm{UPO}}(n)\to1
\]

is a genuinely mesoscopic-to-macroscopic internal module.

The next target is a uniform splitter-cascade or continuum homogeneous-set estimate that crosses the square-root barrier.
