# Current architecture and the origin-of-time problem

**Date:** 2026-11-11  
**Author:** Felipe Gianini Romero  
**Status:** architecture-level scope audit  
**Conclusion:** the current provisional tuple \((R,q,\mu,K,\pi)\) does not non-circularly derive physical time from a timeless substrate

## 1. Purpose

The foundational manuscript correctly describes

$$
\mathcal M=(R,q,\mu,K,\pi)
$$

as a **provisional informational architecture**, not a physical ontology.

The physical bridge has now accumulated enough results to ask a sharper question:

> Does the current architecture already contain the ingredients needed to derive temporal order without assuming it?

The answer is no under the current definitions.

This is a scope result, not a no-go theorem against future extensions or deeper reformulations.

## 2. R

The manuscript defines \(R\) as relational or ordinal structure and explicitly allows application-dependent meanings such as:

- reachability;
- comparability;
- adjacency;
- precedence.

This flexibility is mathematically useful.

For the origin-of-time problem it creates a semantic fork.

### If R already means precedence

Then directional/ordinal information has been supplied as input.

Using it to “derive” temporal precedence would be circular.

### If R means a non-temporal relation

Then the project must state that non-temporal meaning and separately prove when a temporal interpretation follows.

The directed-relation and automorphism audits show that the direction cannot simply be hidden inside vertex labels or arbitrary orientation choices.

Therefore the current symbol \(R\) does not, by itself, solve the origin of temporal direction.

## 3. q

The manuscript introduces \(q\) as additional cardinal information not determined by \(R\).

The present audits now establish several boundaries.

- \(q\) derived from \(R\) adds no information relevant to an \(R\)-equivalence class.
- A genuinely independent \(q\) can break structural symmetries.
- A calibrated scalar \(q\) need not be monotone along physical transitions.
- A scalar potential cannot generate directed cycles through strict gradient orientation.
- The A24 raw reciprocal edge score is not gauge-identifiable across source rows.
- Closed-loop q circulation can be gauge-invariant, but a physical loop field need not define temporal precedence.

Thus

$$
\boxed{
q\text{ can add asymmetry without becoming time}.
}
$$

The physical origin of the actual foundational \(q\) remains open.

## 4. mu

The manuscript assigns \(\mu\) the role of additive refinement mass or multiplicity.

Its purpose is to distinguish:

- descriptive refinement;
- ontic multiplicity;
- conservative weighting.

Nothing in the current \(\mu\) contract supplies a canonical orientation of events or a temporal parameter.

A nonuniform measure can break some symmetries, but that would only provide additional marked information unless a physical temporal meaning is independently derived.

Therefore

$$
\boxed{
\mu\text{ is not currently a time-origin mechanism}.
}
$$

## 5. K

The manuscript defines \(K\) as a conditional transition law.

When \(K\) is interpreted dynamically,

$$
K(i,j)
$$

means a conditional law for moving/evolving from a source state toward a target state.

This is operationally useful.

For a timeless derivation it is dangerous.

If “transition” already means one state occurs after another, then temporal succession is already part of the interpretation of \(K\).

Composition

$$
K,\;K^2,\;K^3,\ldots
$$

then orders repeated updates only because the update semantics have already been supplied.

Therefore one may use \(K\) to study:

- dynamics;
- relaxation;
- memory;
- coarse-graining;
- clocks;
- arrows;

but not claim that temporal succession was derived from nothing if succession was built into the meaning of the kernel.

### Alternative reading

One could try to regard \(K\) as a timeless conditional compatibility object.

Then an additional theorem would still be required to explain why repeated composition should be interpreted temporally.

No such theorem currently exists in the repository.

## 6. pi

The manuscript defines \(\pi\) as occupancy/source weighting for dynamic aggregation.

A snapshot distribution does not determine an order of events.

The same \(\pi\) can appear:

- under different generators;
- under different histories;
- in equilibrium or nonequilibrium contexts;
- at different externally labelled times.

Bridge 2 strengthened this point experimentally: the same complete observed marginal can have different future evolution because hidden information differs.

Thus

$$
\boxed{
\pi\text{ is state information, not a derivation of time}.
}
$$

## 7. The architecture-level fork

The current tuple can be used in two modes.

### Temporally interpreted mode

- directed/precedence-like \(R\);
- dynamical transition \(K\);
- time-indexed \(\pi\);
- possibly time-dependent q.

This mode supports real dynamical modelling.

But temporal structure is already part of the modelling contract.

### Timeless mode

Remove all temporal semantics from:

- direction of \(R\);
- transition meaning of \(K\);
- time indices on q and \(\pi\).

Then the remaining mathematical data do not currently select a unique temporal order.

The audits show:

- passive relation symmetry can block orientation;
- labels cannot supply physical direction;
- q can break symmetry but is not temporal;
- loop circulation can be physical without precedence;
- \(\mu\) and \(\pi\) do not supply a canonical arrow;
- orderability itself may fail in indefinite-causal sectors.

Therefore the current tuple is not yet a timeless foundation.

## 8. This does not invalidate the architecture

The result should not be read as a failure.

The architecture was designed to answer an informational question:

> What information is required for specified relational, quantitative, refinement, transition, and aggregation operations?

It answers that question increasingly well.

It was not originally a theorem deriving time.

The present audit prevents a later category error in which a successful dynamical architecture is retroactively described as a derivation of temporal ontology.

## 9. Strongest current conclusion

The correct statement is:

$$
\boxed{
(R,q,\mu,K,\pi)
\text{ is an effective informational architecture for relational/dynamical modelling,}
}
$$

not

$$
\boxed{
(R,q,\mu,K,\pi)
\text{ currently derives time from a timeless substrate.}
}
$$

The second statement is unsupported.

## 10. What a deeper layer would have to accomplish

A genuinely timeless precursor cannot merely rename the current symbols.

It must explain at least one of the following without presupposing temporal order:

1. why an asymmetric influence/relation exists;
2. why a definite-order sector is selected when it is;
3. how reversible relational change is parameterized internally;
4. how duration is calibrated;
5. how ordinary causal/time structure is recovered in a physical limit.

It must also survive:

- label invariance;
- gauge invariance;
- automorphism no-go tests;
- orderability tests;
- comparison with Page-Wootters;
- comparison with causal sets;
- comparison with process matrices;
- comparison with established coarse-graining and causal-state theory.

## 11. No automatic sixth primitive

This audit does **not** recommend adding a symbol such as

$$
T
$$

or

$$
\chi
$$

to the architecture.

Doing so would merely name the missing structure.

The next step must be obstruction-driven, as the foundational programme already requires.

A new primitive is justified only after a precise operation cannot be supported by the current information and after the candidate has an independent physical or operational meaning.

## 12. Current foundational gap

After the latest audits, the unresolved gap can be written as:

$$
\boxed{
\text{non-temporal primitive structure}
\;\;?\Longrightarrow\;\;
\text{operational asymmetric influence/order}
}
$$

followed separately by

$$
\boxed{
\text{order/clock structure}
\;\;?\Longrightarrow\;\;
\text{physical duration and observed causal time}.
}
$$

Neither arrow is currently proved.

## 13. Research consequence

The immediate research target should no longer be:

> invent an equation for time.

Nor should it be:

> add time to \((R,q,\mu,K,\pi)\).

The correct next target is smaller:

> identify a non-temporal operational structure whose asymmetry is physically justified and determine whether it is sufficient to recover a definite-order sector without importing timestamps or transition-step semantics.

If no such structure is found, that negative result should be retained rather than repaired ad hoc.
