# Pregeometric time bridge — anti-circularity gate

**Date:** 2026-11-11  
**Author:** Felipe Gianini Romero  
**Status:** research-governance gate for any future claim of emergent time  
**Physical status:** no emergent-time result has been established

## 1. Why this gate is necessary

The physical bridge has now established several rigorous facts about dynamical closure, hidden information, environmental memory, and temporal sampling.

Those results all use an external temporal structure in their premises:

- \(t\);
- \(\Delta t\);
- master equations;
- rates;
- relaxation times;
- drive frequencies;
- drive periods;
- time-ordered trajectories.

Therefore they cannot be evidence that time itself emerges.

They can only be evidence about what happens **given an already temporal dynamics**.

This distinction is mandatory.

## 2. Anti-circularity rule

Any future claim that time emerges from relational persistence, informational noise, hidden context, or closure failure must begin from an input description that does **not** already contain the temporal object being derived.

The derivation may not assume as primitive:

- an external real parameter \(t\);
- a time step \(\Delta t\);
- a preordered event sequence interpreted as earlier/later;
- a Markov transition step whose index is already temporal;
- a decay rate;
- a frequency;
- a period;
- a relaxation time;
- a Hamiltonian evolution parameter;
- a causal order imported from spacetime.

If one of these is assumed, the result may concern an **effective timescale** or **relational clock**, but it is not a derivation of time from a timeless structure.

## 3. What the current bridges establish

The present bridges support a narrower statement:

> In systems with an already defined temporal dynamics, the predictive sufficiency of a reduced state depends on retained information, hidden-state persistence, preparation, and temporal resolution.

This is physically meaningful.

It is not a solution to the problem of time.

## 4. Existing approaches that constrain the search

### Causal-set theory

Causal-set approaches take a locally finite partial order as fundamental.

Order can then play the role of causal temporal structure, and cardinality supplies volume information.

This is highly relevant to pregeometry, but it does **not** derive order from closure failure or information loss.

A project construction that simply postulates a partial order would enter causal-set territory rather than explain the origin of that order.

### Page-Wootters relational time

Page-Wootters-type constructions use a globally constrained or stationary state and recover subsystem evolution conditionally relative to a clock subsystem.

This shows how dynamics can be relational even when the global state is constrained.

A project construction based on an internal reference variable must be compared directly with Page-Wootters and relational-clock literature.

### Thermal time

The thermal-time programme associates a flow with a state and an observable algebra through modular structure.

It is a serious benchmark for state-dependent time.

Recent criticism emphasizes a circularity concern: dynamics or temporally loaded structure may already be needed to justify the proposed temporal interpretation.

Any project proposal based on information state or entropy must confront this problem explicitly.

### Causal states and predictive information

Causal states provide minimal sufficient statistics of the past for predicting the future.

They solve a predictive-compression problem.

They do not, by themselves, derive temporal order from a timeless ontology because “past” and “future” are already part of their definition.

## 5. Minimal pregeometric input contract

A genuine project attempt should begin with a structure such as

$$
\mathfrak P_0=(E,\mathcal R,\mathcal A),
$$

where:

- \(E\) is a set of elementary events/configurations;
- \(\mathcal R\) is non-temporal relational data;
- \(\mathcal A\) is any admissibility, compatibility, or probabilistic structure that can be defined without temporal labels.

This notation is schematic.

It is not yet a physical model and should not be promoted into one until each component has an operational or mathematical justification.

## 6. Milestone P0 — label invariance

Any candidate temporal order must not depend on arbitrary labels assigned to the primitive elements.

If two primitive structures are isomorphic, the derived temporal structure must be isomorphic as well.

Otherwise “time” is being inserted through indexing.

This requirement aligns with the covariance concerns that also appear in causal-set approaches.

## 7. Milestone P1 — derive an order candidate

The first real mathematical target is not a metric and not an equation of motion.

It is an internally derived binary relation

$$
\prec
$$

on a subset or quotient of the primitive structure.

The project must state a non-temporal rule for when

$$
e\prec f.
$$

Then it must prove or refute the properties needed for a temporal/causal interpretation.

At minimum investigate:

- irreflexivity;
- asymmetry;
- transitivity;
- acyclicity;
- local finiteness or an alternative discreteness condition.

Taking a transitive closure after the fact is not automatically acceptable. If cycles or contradictions are present, the physical meaning of removing them must be justified independently.

## 8. Milestone P2 — distinguish order from duration

A partial order supplies before/after structure, not a metric duration.

The programme must not silently identify

$$
e\prec f
$$

with a numerical elapsed time.

A second construction is required for duration.

Possible benchmark structures include:

- chain length or counting in causal sets;
- internal relational clocks;
- clock-system correlations;
- state-dependent modular flow.

The project must demonstrate why its duration variable corresponds to a physical clock rather than merely to graph distance or algorithmic depth.

## 9. Milestone P3 — recover known temporal physics

A successful pregeometric construction must recover an accepted temporal description in a controlled limit.

Depending on the route, this could mean recovering:

- a Markov semigroup;
- a Schrödinger-type relational evolution;
- Lorentzian causal order;
- proper-time relations for suitable clocks;
- a continuum causal structure.

The recovery must include a mapping from primitive variables to physical observables.

Qualitative resemblance is not sufficient.

## 10. Milestone P4 — clock consistency

If multiple internal subsystems can act as clocks, the construction must determine when they agree.

Questions include:

- monotonicity;
- synchronization;
- clock ambiguity;
- backreaction;
- finite-resolution error;
- whether different clocks induce equivalent orderings.

This is already a central issue in relational-time approaches.

A project result must be compared against that literature.

## 11. Milestone P5 — empirical or model-discriminating consequence

A timeless construction that merely reproduces standard dynamics after enough freedom is not yet physically informative.

At least one of the following is required:

1. a parameter-free recovery result;
2. a nontrivial no-go theorem;
3. a new mathematical constraint on admissible temporal structures;
4. a prediction that differs from a simpler established model;
5. a held-out physical test.

No post-hoc adjustment after inspecting the target observable may be counted as confirmation.

## 12. Status of the user's working hypothesis

The working intuition can be stated cautiously as:

> temporal structure may be related to the ordering required to describe persistent relational change under unresolved external influence.

This is currently a **research motivation**, not a physical hypothesis with a defined model.

The stronger statement

> time emerges when a relation cannot absorb informational noise for long enough

is not yet mathematically well-defined because the phrase “for long enough” already contains temporal content.

This is the first circularity that must be removed.

A timeless version must replace “for long enough” with a non-temporal structural condition.

## 13. A non-temporal reformulation target

A safer research question is:

> Can a directed order be derived from asymmetries of relational compatibility, recoverability, or conditional dependence without assuming an external temporal ordering?

This question does not yet specify the answer.

It creates a falsifiable mathematical task:

- define the asymmetry without time;
- test whether it generates a consistent order;
- classify counterexamples;
- compare the result with causal-set, causal-inference, and relational-clock theory.

## 14. What must not be done

The bridge must not:

- rename a Markov step as emergent time;
- rename relaxation time as fundamental time;
- infer spacetime from a memory kernel;
- call graph depth physical duration without a clock correspondence;
- introduce an order relation solely because a temporal interpretation is desired;
- select a preferred direction after looking at the desired physical outcome;
- hide a temporal label inside “update number,” “iteration,” “layer,” or “generation.”

## 15. Current conclusion

The physical bridge has advanced far enough to make a strong negative statement:

$$
\boxed{
\text{memory/closure results obtained with }t\text{ already present do not establish emergent time.}
}
$$

This negative result is useful because it prevents a false bridge.

The next pregeometric milestone is therefore not another dynamical fit.

It is the derivation—or failure to derive—an unlabeled order candidate from genuinely non-temporal relational structure.
