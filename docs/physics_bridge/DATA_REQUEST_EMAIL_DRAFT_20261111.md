# Draft data request to the Salhani et al. authors

**Date prepared:** 2026-11-11  
**Status:** draft only; not sent by the repository  
**Intended corresponding author:** Katsuhiko Nishiguchi

## Subject

Request for phase-resolved or time-resolved data from PRR 8, 023209 (2026)

## Draft

Dear Professor Nishiguchi,

My name is Felipe Gianini Romero, and I am an independent researcher working on mathematical questions about reduced descriptions and dynamic closure in stochastic systems.

I have been studying the master equation reported in your paper with Chloe Salhani, Kensaku Chida, Takase Shimizu, and Toshiaki Hayashi, “Heat-dissipation decomposition and free-energy generation in a nonequilibrium dot with multiple electron states,” Physical Review Research 8, 023209 (2026).

I am interested in a narrow reproducibility question concerning transforms of the measured electron-number distribution. I have derived the proposed test from the rate law in the paper and fixed the analysis protocol before accessing the underlying experimental data. I am not treating the result as evidence for a new thermodynamic law.

Would it be possible to obtain the numerical data underlying the time-dependent distributions rho_N(t), preferably in a machine-readable form?

For the strongest version of the test, the most useful data would be either:

- individual electron-count trajectories with the randomized ac phase recorded for each repetition; or
- probability distributions conditioned on phase bins, rho_N(t | phi).

If phase-resolved data are not available, the phase-averaged rho_N(t) values used for the transient figures would still be useful. In that case I would restrict the exact analysis to the pre-registered stroboscopic recurrence at integer drive periods and treat the continuous-time averaged-rate equation only as the approximation described in the paper.

Useful metadata, if readily available, would include the exact time points, electron-number state window, E_C and its uncertainty, temperature, Gamma_0, S_AC, drive frequency, phase convention, detector time resolution, and any correction for missed transitions.

I will preserve the original files unchanged, document parameter provenance, and will not redistribute any non-public data without permission. If the data cannot be shared, I completely understand.

The purpose of the analysis is simply to test whether a reduced transform coordinate derived from the published master equation behaves as predicted when confronted with the underlying measurements.

Thank you for considering the request, and thank you for making the physical model and experimental methodology clear enough to support an independent analysis.

Best regards,
